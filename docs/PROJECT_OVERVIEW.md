# HobbyMatch - Telegram Mini App для поиска партнеров по хобби

## Описание проекта

HobbyMatch — это Telegram Mini App для поиска партнеров по спорту и хобби через dating-механику (свайпы). Решает проблему одиночества и сложности поиска единомышленников для совместных активностей.

## Ключевые особенности

- 🎯 Dating-механика для поиска партнеров по хобби
- 🌳 Умное дерево категорий (155+ видов спорта и хобби)
- 📍 Геолокация и фильтрация по расстоянию
- 💬 Встроенный чат для договоренностей
- 📅 Система предложения встреч
- ⭐ Рейтинг надежности пользователей
- 💎 Freemium монетизация

## Целевая аудитория

**Primary:**
- Студенты 18-25 лет (переехавшие в новый город)
- Young professionals 23-35 лет (хотят новые хобби)

**Secondary:**
- Переехавшие / удаленщики
- После декрета

## Бизнес-модель

**Freemium:**
- Free: 10 свайпов/день, базовые фильтры
- Premium: 490₽/мес — безлимит свайпов, расширенные фильтры
- In-app: Boost (99₽), Super Swipes (49₽/шт)

## Tech Stack

**Frontend:** React + TypeScript + Vite + Tailwind + Telegram WebApp SDK  
**Backend:** Python + FastAPI + PostgreSQL + Redis  
**Infrastructure:** Railway (backend), Cloudflare R2 (фото)

## Ключевые метрики успеха

- 40%+ Day-1 Retention
- 20%+ Week-1 Retention
- 5% конверсия в Premium к Month-3
- 20%+ пользователей получают минимум 1 match в первую неделю
