3️⃣ DISCOVERY (Свайпы)Действие:

Видит карточки пользователей с фото
Информация на карточке:

Имя, возраст
Общие интересы (badges)
Расстояние (2.5 км)
Skill level


Свайп влево → Pass
Свайп вправо → Like
10 свайпов в день (Free tier)
Match Score (внутренний алгоритм):
Система показывает людей с наибольшим Match Score:

50 points: Общие интересы (10 за каждый, max 5)
20 points: Расстояние (ближе = лучше)
15 points: Одинаковый skill level
15 points: Availability совпадает
Filters:

✅ Минимум 1 общий интерес
✅ Расстояние ≤ max_distance_km (10 км default)
✅ Пол = partner_gender_preference (any/male/female)
✅ Не показывать: уже просмотренных, blocked, с кем есть match
Мысли:

"О, тут реально есть люди!"
"Этот слишком далеко"
"У нас одинаковый уровень, круто"

Goal: 20%+ получают Match в первые 10 свайпов
